1. Introduction

Mission. Junction connects commerce, community, pledges, and sustainability into one ecosystem.

Vision. A unified platform where trust, responsibility, and innovation drive user experience.

Philosophy. One job per control. No decoration for its own sake. Platforms differ in voice, not in hue.

2. Brand identity

Core values: Trust, responsibility, community, sustainability. Tone: clear, approachable, inclusive, slightly technical.

Junction

Today · Website · Blog · Monster · Earth

Do

Keep gold field + forest J. Clear space. Paper or forest backgrounds. Favicons from branding/.

Don’t

Distort the mark, recolor the J, use Inter/Helvetica, busy photos, or the Angular default favicon.

3. Color system

Rejected: per-platform blue / orange / crimson / teal tables. All five sites already share forest, gold, and paper.

9. Code standards

CSS variables on :root. BEM for new shared classes. Angular first. Light color-scheme. Localize without baking English widths.

  --forest: #194b31;
  --gold: #f3d782;
  --paper: #f4f0e6;

}
